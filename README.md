# 🧭 gmc_fixmap

**コマンド 1 つでミニマップを「北が上」に固定できる、FiveM 用の小さなリソース**

</div>

GTA5 のロールプレイサーバー「GMC RP」向けに作った FiveM のリソースです。
GTA5 のミニマップは、ふだんはキャラクターの向きに合わせて回転します。
`/fixmap` と入力すると、ミニマップが北を上にしたまま固定され、もう一度入力すると元に戻ります。

GMC RP は約 2 年間、日本トップの人気を誇ったサーバーです。
このリソースのほかに、ゲーム内スマホのアプリ「Style N&B」や、「新商品申請フォーム」などの Web アプリも作りました。

## 使い方

| コマンド | 動作 |
| --- | --- |
| `/fixmap` | ミニマップを北に固定する（固定中なら解除する） |

切り替えたときは、画面に「マップを北に固定しました」「マップの固定を解除しました」と通知が出ます。

## 工夫したところ

- **1 つのコマンドでオン・オフ**：覚えるコマンドを 1 つだけにして、入力するたびに固定と解除が切り替わるようにしました
- **サーバーの通知に合わせた表示**：QBCore の通知機能を使い、ほかの機能と同じ見た目で状態を知らせます
- **小さく保つ**：GTA5 のネイティブ関数を直接呼び出すだけの作りにして、クライアント側のスクリプト 1 つで完結させています
